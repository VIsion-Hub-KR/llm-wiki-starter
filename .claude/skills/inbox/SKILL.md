# /inbox — 수집 대기소 점검·처리

## 전제

- `/setup` 완료 후에만 쓴다. 루트 `CLAUDE.md`와 `01. Inbox/CLAUDE.md`의 규칙을 따른다. 호칭·언어는 루트 CLAUDE.md §4.
- Inbox는 대기열이지 아카이브가 아니다 — 목표는 항상 **비우는 것**.

## 절차

1. **스캔** — `01. Inbox/`의 모든 항목 수집 (CLAUDE.md·.gitkeep 제외): 파일은 frontmatter/첫 줄에서 맥락 탐색, 메모 파일은 `- [ ] <제목/URL> — 왜: ...` 형식 파싱.
2. **보고** — 표: | 항목 | 들어온 날 | 맥락(왜) | 상태 | — ✅ 맥락 있음 / ⚠️ 맥락 없음(물어야 함) / ⏸ 보류.
3. **맥락 없는 항목** — 하나씩 묻는다: "왜 수집하셨어요? 지금 하는 일과 어떻게 연결돼요?" 답을 항목에 기록. **답 없이는 인제스트하지 않는다** (Gold In Gold Out).
4. **처리 확인** — 맥락 있는 항목에 "지금 인제스트할까요?" 확인 후 `/ingest` 절차로. 처리 완료 항목은 Inbox에서 **제거** (원본은 Raw에 있다).
5. **백업** — 변경이 있었으면 루트 CLAUDE.md §4의 백업 설정을 따른다.

## 보고 형식

`총 N건 — 처리 가능 n / 맥락 필요 n / 보류 n` + 표. 빈 Inbox면 "인박스가 비어 있습니다 ✨" 한 줄.

## 금지

- 맥락 없는 항목의 무단 인제스트 · Inbox 항목을 사용자 확인 없이 삭제 (인제스트 완료에 따른 제거만 허용)
