# /query — 위키 질의

## 전제

- `/setup` 완료 후에만 쓴다. 루트 `CLAUDE.md`와 `30. Queries/CLAUDE.md`의 규칙을 따른다. 호칭·언어는 루트 CLAUDE.md §4.
- 답변의 1차 해석 렌즈: 루트 CLAUDE.md §3의 렌즈 문장.

## 절차

1. **탐색 순서 (헌법 규칙 8 + 도메인 렌즈)** — ① 질문의 업무 좌표 판별(`90. Settings/Domain_Registry.md`) → 해당 `WS — {Domain}` 맵에서 후보 선정 (도메인 불명이면 `00. Core/WS — Home.md` 트리로 내려간다) → ② `00. Core/index.md`로 보충 → ③ 해당 위키 페이지 읽기 (wikilink 체인) → ④ `30. Queries/` 기존 답변 확인 → ⑤ 부족할 때만 `10. Raw Sources/` 원문.
2. **답변 작성** — 종합해서 답한다. 모든 주장에 근거 위키 페이지를 `[[wikilink]]`로 표기. 소스 간 모순이 있으면 양쪽 다 인용 (규칙 6). 위키에 없는 내용은 "위키에 없음"을 명시하고 일반 지식과 구분한다.
3. **저장 판단** — 재사용 가치가 있으면 `30. Queries/YYYY-MM-DD_질문-요지-슬러그.md`로 저장 (같은 주제 기존 파일이 있으면 갱신). 일회성이면 저장하지 않는다.
4. **기록** — 저장했으면 index "30. Queries" 섹션에 한 줄 + log에 `[query]` 기록.
5. **승격 제안** — 답변이 질문 맥락을 벗어나 독립 지식이 됐으면 `21. Concepts/`·`24. Guides/` 승격을 제안한다.
6. **백업** — 파일 변경이 있었으면 루트 CLAUDE.md §4의 백업 설정을 따른다.

## 보고 형식

답변 본문 → 하단에 `근거: [[페이지1]] · [[페이지2]] …` + 저장 여부 한 줄.
