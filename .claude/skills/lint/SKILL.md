# /lint — 위키 건강 점검

## 전제

- `/setup` 완료 후에만 쓴다. 루트 `CLAUDE.md` 규칙을 따른다. 호칭·언어는 루트 CLAUDE.md §4.
- 점검 대상: `20. Wiki/` 전체 + `30. Queries/`. (10. Raw Sources/는 불변 — 참조 무결성만 확인)

## 점검 항목 (8종)

1. **깨진 wikilink** — `[[대상]]`이 실제 파일로 존재하지 않는 링크 (의도적 미래 링크와 오타를 구분).
2. **index 정합성** — index에 없는 페이지 / index에 있는데 파일 없음 / 한 줄 120자 초과.
3. **frontmatter** — 누락 페이지, 필수 필드(title·type·created·updated) 빠짐, type 값이 스키마 밖, source 타입인데 source_raw 없음·경로 실존 안 함.
4. **고아 페이지** — 어디서도 링크되지 않고 index에만 있는 페이지 (연결 제안).
5. **모순·중복** — 페이지 간 상충 서술(규칙 6 위반 후보), 사실상 중복 (병합 제안).
6. **낡은 정보** — 시점 병기 수치의 노후화, "예정"·"보류" 항목 상태 확인 (사용자에게 질문 목록으로).
7. **살아있는 참조** — `00. Core/Who am I.md` 최종 수정이 **30일 초과**면 🟡 갱신 검토 경고 (사용자 유지 문서 — 알림만).
8. **도메인 좌표** — ① `domains` 미표기 페이지 집계, ② `90. Settings/Domain_Registry.md` 등재 밖 값 (🔴), ③ WS 맵 정합 — 도메인 값은 있는데 맵 미등재(등재 제안) / 맵에 있는데 파일 없음·도메인 불일치(🔴).
   - (탐색 게이트 모듈 활성 시 추가) `explored: false` 백로그 집계, `confidence: high`인데 편향 점검 콜아웃 없는 페이지 경고.

## 절차

1. 전수 스캔 (링크·frontmatter는 기계 점검, 모순·중복은 내용 판독).
2. **보고** — 항목별 건수 + 상세 표 (🔴 즉시 수정 / 🟡 판단 필요 / ⚪ 참고).
3. **수정** — 기계적 오류는 바로 수정(보고에 명시), 판단 필요한 것은 사용자 확인 후.
4. **기록** — log에 `[lint]` 요약. **백업** — 수정이 있었으면 루트 CLAUDE.md §4 설정대로.

## 권장 주기

인제스트 10건마다 또는 주 1회. 대량 인제스트·구조 변경 직후는 필수.
