Bespoke LLM Wiki가 세팅됩니다.

AI가 유지·관리하는 지식 위키 — 설치는 당신의 컴퓨터에서, 당신의 에이전트가 수행합니다. 설치 인터뷰가 당신이 일을 나누는 방식을 묻고, 그 좌표계로 위키의 계층 구조를 만듭니다. 기성복 템플릿이 아니라 맞춤복입니다.

15–20분 무료 Claude Code 본인 환경에서 실행

1킷 받기

위키가 살 폴더 위치까지 한 줄에 들어 있습니다. 경로(~/Documents/Bespoke LLM Wiki)는 원하는 대로 바꿔도 됩니다 — 명령 세 줄 중 첫 줄입니다. (요구사항: Obsidian · Claude Code)

git clone https://github.com/VIsion-Hub-KR/bespoke-llm-wiki-starter.git ~/Documents/"Bespoke LLM Wiki"

git이 없다면: ZIP 다운로드 후 원하는 위치에 압축 해제. 킷 내용물은 GitHub에서 전부 열람 가능합니다.

2실행

폴더에 들어가 Claude Code를 켜고 한 마디 — 여기까지가 명령 세 줄의 전부입니다:

cd ~/Documents/"Bespoke LLM Wiki" && claude 설치해줘 # 또는: /setup
01정체성 인터뷰
02좌표 — 일을 나누는 방식
03용도·발행 채널
04소스 습관
05운영·백업
06위키 생성 + 첫 인제스트

기존 노션·옵시디언 시스템이 있다면 인터뷰가 그것을 판독해 좌표를 뽑아냅니다. 끝나면 Obsidian으로 폴더를 열어(Open folder as vault) 완성된 위키를 확인하세요.

3설치 후엔 세 문장

위키의 유지보수는 전부 AI의 일입니다. 당신은 좋은 자료를 던지고, 좋은 질문을 던지면 됩니다:

이거 위키에 넣어줘 # 인제스트 — 자료를 소화해 위키에 축적 위키에서 OO 찾아줘 # 질의 — 쌓인 지식으로 답변 위키 건강 점검해줘 # 린트 — 깨진 링크·모순 점검

이 킷의 약속

  • 원본은 불변 — 수집된 자료의 원문은 절대 수정되지 않고, 모든 지식은 원 출처까지 추적 가능한 사슬로 연결됩니다.
  • 목적 있는 수집만 — "왜 수집했는지" 답할 수 없는 자료는 위키에 들어가지 않습니다 (Gold In Gold Out).
  • 폴더가 아니라 좌표 — 지식은 여러 영역에 걸칩니다. 좌표(태그)와 워크스테이션 맵이 폴더 대신 분류를 맡아, 역할·팀이 늘어도 폴더 재편 없이 확장됩니다.
  • 전부 열람 가능 — 스킬·템플릿·규칙 문서가 모두 마크다운으로 공개돼 있습니다. 숨긴 동작은 없습니다.

FAQ

옵시디언을 써본 적이 없어요.
괜찮습니다. 옵시디언은 "폴더 속 마크다운 파일을 예쁘게 보여주는 뷰어"로만 쓰면 됩니다. 정리·연결·목차 관리는 전부 AI가 합니다.
이미 노션·에버노트에 자료가 많아요.
그 도구는 "원본 도서관"으로 계속 쓰고, 이 위키는 그중 중요한 것만 소화하는 층으로 두면 됩니다. 설치 인터뷰에서 알려주시면 기존 시스템을 판독해 당신의 좌표계를 뽑는 데도 씁니다.
자료를 다 옮겨야 하나요?
아니요. 전부 옮기는 순간 위키는 저품질 복사본이 됩니다. "왜 수집했는지" 답할 수 있는 것만 넣는 게 이 시스템의 핵심 규칙입니다.
어디서 온 방법론인가요?
안드레 카파시(前 테슬라 AI 총괄)의 LLM Wiki 패턴이 뿌리입니다. 여기에 이현석(비전허브)의 운영 볼트에서 검증된 도메인 좌표계·워크스테이션 맵·설치 인터뷰를 얹어 일반화했습니다.
