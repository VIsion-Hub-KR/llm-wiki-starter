# 90. Settings/ — 규칙·시스템 파일

위키 시스템의 **설정·규칙 파일**을 둔다. 지식도 참고자료도 아닌, 시스템 자체를 구성하는 파일.

## 들어가는 것

- `Domain_Registry.md` — 도메인 좌표계 마스터 (설치 인터뷰가 생성, 확장 시 여기에 1줄 추가)
- `Templates/starter/` — 설치·확장에 쓰는 템플릿 (WS 맵 템플릿은 새 도메인 개설 때 재사용)
- 자동화 설정·스크립트 (스킬이 참조하는 데이터)

## 규칙

- 실질적 시스템 규칙의 최상위는 항상 **루트 CLAUDE.md** — 여기 파일은 그 보조. 충돌하면 루트가 이긴다.
- 스킬 정의 자체는 `.claude/skills/`에 있다 (Claude Code 규약 위치). 여기는 스킬이 **참조하는 데이터**를 둔다.
- 시스템 파일을 수정하면 의존하는 문서(루트 CLAUDE.md·스킬·폴더 CLAUDE.md)도 함께 갱신한다.
