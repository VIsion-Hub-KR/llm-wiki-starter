# 10. Raw Sources/ — 불변 원본 사본

**이 폴더의 파일은 절대 수정하지 않는다** (위키 헌법 규칙 1). 읽기만 허용. 오타·오류가 있어도 그대로 둔다 — 수정·해석은 20. Wiki/에서 한다.
단, **인제스트 시점에 불완전한 원본(저자·출처 누락 등)은 검색으로 보강해 온전한 형태로 만든 뒤** 저장한다. 저장된 후에는 불변.

## 하위 폴더 (표준 슬롯 — 설치 인터뷰에서 해당분만 개설, 번호는 고정)

| 폴더 | 들어오는 것 |
|---|---|
| `11. Articles/` | 웹 아티클·외부 문서·스크랩 |
| `12. Papers/` | 논문·리포트·PDF 문서 (텍스트 추출본 포함) |
| `13. Books/` | 책 발췌·독서 노트 |
| `14. Transcripts/` | 회의·강연·녹음 전사 |
| `15. Videos/` | 유튜브 등 영상 전사 |
| `16. My-Content/` | 사용자가 직접 쓴 글 (원고·대본·발행물) |

나중에 새 유형이 생기면 빈 번호 슬롯으로 폴더를 추가한다 (순서가 꼬이지 않도록 번호는 재사용·재배치하지 않는다).

## 파일 규칙

- 파일명: `YYYY-MM-DD_슬러그.md` (예: `2026-07-17_카파시-LLM-Wiki-gist.md`)
- frontmatter 필수 — 최소: `title`, `type: raw`, `collected: YYYY-MM-DD`, `origin_url:` (원 출처 URL — 외부 도서관(노션 등) 출처면 그 원본 URL), `why_collected:` (Gold In Gold Out)
- 유입 통로: ① 외부 도서관(노션 등, 이미 정리된 것) → `/ingest` 직행 ② 웹 직수집 → `01. Inbox/` → `/ingest`(1차 정리) 후 합류. 수동으로 넣을 때도 같은 frontmatter를 지킨다.
