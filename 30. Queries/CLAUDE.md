# 30. Queries/ — 질의 답변 저장소

사용자가 위키에 던진 **질문과 그 답변**을 저장하는 곳. 여러 위키 페이지를 종합해 나온 답은 어느 한 페이지에도 없던 새 지식이므로, 저장해서 다음 질문의 출발점으로 쓴다 (카파시: "탐색도 복리로 축적된다").

## 구조

- **하위 폴더 없음.** 질의 1건 = 파일 1개, 플랫하게 쌓는다. 파일이 **100개를 넘으면** 그때 연도 폴더로 샤딩한다 (전환 시 log 기록 + 이 문서 개정).
- 파일명: `YYYY-MM-DD_질문-요지-슬러그.md`
- 모든 답을 저장하지 않는다 — **재사용 가치가 있는 좋은 답만** (일회성 확인 질문은 저장 안 함).

## 파일 형식

```markdown
---
title: (질문 요지)
type: query
created: YYYY-MM-DD
updated: YYYY-MM-DD
domains: []
question: "(사용자의 원래 질문 그대로)"
related: ["[[답변에 사용한 위키 페이지들]]"]
---

# (질문 요지)

**Q**: (질문 원문)

## 답변

(종합된 답변 본문 — 근거 위키 페이지는 [[wikilink]]로)

## 이 답이 쓰인 곳 (누적)

- YYYY-MM-DD: (예: 발표 자료에 반영)
```

## 작업 규칙

- 저장 시 `00. Core/log.md`에 `[query]` 프리픽스로 기록. `00. Core/index.md`의 "30. Queries" 섹션에도 한 줄 추가.
- 같은 주제로 다시 질문이 오면 **새 파일 대신 기존 파일을 갱신**.
- 답변이 충분히 일반화되면 `21. Concepts/`나 `24. Guides/`로 승격시키고, 여기 파일에는 승격 링크를 남긴다.
